# EdTech Student Progress Tracking and Learning Analytics Discord Bot

A Discord bot for online course creators, bootcamp instructors, and university teaching assistants. Tracks student assignment submissions, quiz scores, and forum participation. Automatically alerts instructors when students fall behind on milestones, sends motivational check-ins to at-risk learners, posts weekly class progress summaries, and tracks cohort completion rates.

## Setup
1. Set `TELEGRAM_BOT_TOKEN` in `.env`
2. `pip install -r requirements.txt`
3. `python main.py`
